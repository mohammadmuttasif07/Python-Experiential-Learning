
# Rolling Dice Simulator 🎲

A simple dice rolling project made using Python and Streamlit.

## Features
- Roll 1 to 10 dice
- Display dice results
- Calculate total
- Show roll history
- Display statistics
- Download roll history

## Technology Used
- Python
- Streamlit

## Run the Project
Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
